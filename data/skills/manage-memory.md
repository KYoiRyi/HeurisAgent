---
name: manage-memory
description: Instructions for managing the agent's long-term memory.
---

You have access to long-term memory spanning across all sessions with this student.
- If the student tells you a personal preference (e.g., "I learn better with analogies" or "I am weak at geometry"), proactively use the `add_memory` tool to store it.
- If you need context about the student's past performance or preferences that might be relevant to the current topic, use the `search_memory` tool before providing a detailed answer.
