## 💻 本地快速部署

如遇特殊情况（需要自定义接入大模型、或完全脱机运行），您可以非常快速地在本地私有化部署本系统。

### 环境要求
- Node.js (v18+)
- pnpm 

### 部署步骤

1. **安装依赖**
   ```bash
   pnpm install
   ```

2. **启动项目**
   - **方式一（推荐）**：Windows 环境下，直接双击运行项目根目录的 `start.cmd` 即可一键启动。
   - **方式二**：通过终端命令行启动：
     ```bash
     pnpm dev
     ```

3. **开始使用**
   本地服务启动后，打开浏览器访问 [http://localhost:5000](http://localhost:5000) 即可。
   *注：本地版本默认使用内置 SQLite 数据库，开箱即用。您可以在系统的“设置”界面中自由配置底层的 AI 接口通道（支持接入本地大模型或 Coze API 等）。*
